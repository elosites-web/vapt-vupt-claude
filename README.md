# Vapt Vupt Remoção de Veículos — protótipo de site institucional

Site estático (HTML, CSS e JS), sem build. Para ver: abra `index.html` ou use GitHub Pages (Settings > Pages > branch `main`, pasta `/root`).

Protótipo privado: `noindex` ativo, formulário sem envio, imagens retiradas das redes sociais da empresa.

## Pendências com o cliente
- Horário de funcionamento e área de atendimento (não exibidos).
- CNPJ e endereço da matriz (hoje só a filial de Jundiaí).
- Confirmar "mais de 30 anos no mercado" e a quantidade exata.
- Fotos reais e em alta resolução da frota e do pátio; confirmar uso das imagens de parceria e do pátio (parecem de banco de imagens).
- Backend do formulário (endpoint, e-mail) e política de privacidade revisada por advogado.
- Domínio de produção, Open Graph com imagem, remover `noindex` ao publicar.
